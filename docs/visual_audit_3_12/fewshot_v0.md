## 評価者の観察順序

1. W1: 大局、高値/安値圏、長期MA、週足由来の水平線を文脈として記す。W1単独で合否を決めない。
2. D1: ダウ、MAとの乖離、次の反対勢力を記す。
3. H4: 対象の型（押し目/戻り目、転換、第1波、乖離埋め）と波の位置を特定する。
4. H1: 上位足の局面を実行可能な波へ落とし込めているかを見る。
5. M15: 記事がM15を執行足にした場合だけ、W底/Wトップ、安値切上げ/高値切下げとネック/直近高安抜けを確認する。記述がなければ補わない。

## 1. 「現在のMA」と「将来のMA」を分ける

- 現在スナップショット: 「上向き」「下向き」「水平」「伸び切り」「MAが価格を支える/抑える」。
- 将来形: 「直近高値を超えればH1MAが上向きを確定」「H1MAがH4MAへ収束後に拡散」「W1MAへD1MAが今後収束」など、条件付きの予想。
- 例: T02は現在のH4MAが水平、将来は価格が抜ければ上向き。T30は現在のH1MAが下向きの勢いを失い上向き始め。これらを「すでに上向き確定」と書き換えない。

## 2. 水平線とH4 MA支えを同一視しない

- 水平の支え: 過去高値/安値、ネックライン、レジサポ転換線（T17, T18, T27〜T30）。
- 斜めの支え: H4MA、D1MA、週足MA（T03, T13, T17, T27〜T30）。
- 両方ある記事は2根拠として別記する。H4MAが描かれているだけで「H4MA支え」としない。
- T01のように水平線は支えだが、行き先には抵抗帯と下降TLがある場合、支えと抵抗を相殺せず両方残す。

## 3. 5つの構造を必ず別欄にする

- 支え: エントリー方向を後押しする足元の水平線/MA/波。
- 抵抗: 取引方向の前方にある過去高安、上位MA、TL/チャネル、次の節目。
- 引き金: 注文を発動させる直近高値/安値、ネック、MA抜け、成行点。
- 無効化/SL: 根拠が崩れる場所または記事が実際に置いた決済線。明記なしなら「原典記述なし」。
- T1: 最初の利確先。抵抗と一致することはあるが、抵抗が自動的にT1になるとは限らない。

短い対比例:

- T03 買い: 支え=上昇H4MA、抵抗=下向きD1MA、引き金=M15 W底ネック越え、T1=D1MA到達、SL価格=原典記述なし。
- T30 買い: 支え=D1レジサポ線+週足MA、抵抗=下降H4MA、引き金=M15 W底ネック付近、T1=H4MA、SL=原典記述なし。
- T29 買い: 標準引き金はH1 W底ネック超えだが、実際はその前の成行。標準形と実執行を混ぜない。

## 4. 型を混ぜない

- 順張りのH4押し/戻り（T03, T08〜T21, T26〜T29）と、上位MAへの乖離埋め（T01, T02, T30）を同じ合否規則にしない。
- 第1波の早入り（T02, T04）、H4転換（T12）、H1押し/戻り（T15, T16, T23, T25）も個別に読む。
- 「H4MA支えがないから不合格」のような単一既定値を置かない。T01/T02/T30では狙いそのものが上位MAまでの乖離埋めである。

## 5. 判断練習と結果確認を分離する

### 判断の練習

- 注文/成行の直前に確定したバーまで。
- 未来の価格、結果節、利確画像、勝敗語を見ない。
- その時点で明示できるW1→D1→H4→H1→M15、5構造、MAの現在/将来を答える。

### 結果の確認

- 回答を固定した後でのみ見る。
- 「勝ったから支えだった」「到達したからT1だった」と遡及定義しない。
- 利確移動、半分決済、事後のトレンド崩れは結果側に置く。

### pass（判定保留）

- 記事レベルの特定を画像が支えない、矢印が曖昧、直前確定バーが一意でない、または必要時間足が事後画像しかない場合は `pass`。
- T02/T05/T27は教材から消さず、判断練習だけ除外する。理由を機械的に残す。
