## 既存CSVとのOHLC全行照合

同一 timestamp の `open`・`high`・`low`・`close` を Decimal として比較した。全重複行で不一致0件。したがって既存データと同じ取得元・同じOHLC系列であることを確認し、新規ファイルを描画用に採用する。

| 銘柄 | 時間足 | 重複期間 | 重複件数 | OHLC不一致 | 最初の不一致 |

| BTC | D1 | 2021-01-01 00:00〜2026-09-12 00:00 UTC | 2,081 | 0 | なし |
| BTC | H4 | 2021-01-01 00:00〜2026-09-13 00:00 UTC | 12,487 | 0 | なし |
