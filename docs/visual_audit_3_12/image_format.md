# 周回3-12 固定画像形式

## 5枚と表示本数

判断時点以前に確定した足だけを使い、各IDにつき次の5枚を別ファイルで描く。

| 時間足 | 表示本数 | MA |
|---|---:|---|
| W1 | 156 | 青20・赤80 |
| D1 | 365 | 青20・赤100・黄400 |
| H4 | 360 | 青20・緑80・赤120・黄600 |
| H1 | 180 | 青20・赤80・黄480 |
| M15 | 180 | 青20・赤80・黄320 |

MA期間と色は `scripts/render_candidate_charts.py` の `MA_PERIODS_*` と `MA_COLOR` を import し、二重定義しない。

## 判断時点と表示

- 採用する足: `bar.timestamp + timeframe_length <= judgment_ts`。足の確定時刻が judgment_ts 以前の足だけ
- W1: D1から月曜0時UTC始まりで組み立て、週末（月曜0時UTC）が judgment_ts 以前の週だけ
- 未来足を含めない。判断時点後のデータを変えても描画対象とMAは変わらない
- 日付・時刻・絶対価格ラベルを表示しない。横軸は相対バー番号、縦軸数値は非表示
- 水平線、ピボット、注記、方向・型・正解、候補マーカーを描かない
- 画像を縮めず、各時間足を独立した12×7 inch画像として保存する
- 出力名: `{id}_w1.png`、`{id}_d1.png`、`{id}_h4.png`、`{id}_h1.png`、`{id}_m15.png`

## 暖機

2017年8月からの新規データ全体でMAを計算してから表示窓を切る。MAの値がまだ計算できない区間は欠損のまま途中から描き、対象IDは落とさず、表示本数も変えない。

| ID | 時間足 | 途中から始まるMA | 表示窓先頭の欠損本数 |

| S19 | W1 | MA80 | 11 |
